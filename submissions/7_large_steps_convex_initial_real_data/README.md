# Submission 7 – Fine Non-Convex Inversion using Mitsuba Forward

This folder contains submission 7 for the Technical University of Denmark (DTU) team to the challenge.

- Submission Repository: [deding2000/HAC-DTU-Mitsuba_real_intensity](https://github.com/deding2000/HAC-DTU-Mitsuba_real_intensity)
- Submission Responsible: Christian Deding Nielsen `<cadni@dtu.dk>`

The submitted reconstructions may be found in [`submitted_reconstructions/`](submitted_reconstructions/).

The full submission repository is present as a _Git Submodule_ in [`submission_repo/`](submission_repo/) and accessible if you have cloned this repository with submodules and have had the appropriate access to the submission repository.

## Terse Description

Non-convex inversion using large-steps optimisation on differentiable ray-tracing forward from convex initial guess. Features relatively fine mesh and less aggressive choice of hyperparameters than submission 6.

For longer description, refer to the report in [`/report/`](/report/).
