This folder contains submission 5 for the Technical University of Denmark (DTU) team to the challenge.

- Submission Repository: [Magnushhhh/Convex-Joint-HAC-DTU](https://github.com/Magnushhhh/Convex-Joint-HAC-DTU)
- Submission Responsible: Magnus Holm `<magho@dtu.dk>`

The submitted reconstructions may be found in [`submitted_reconstructions/`](submitted_reconstructions/).

The full submission repository is present as a _Git Submodule_ in [`submission_repo/`](submission_repo/) and accessible if you have cloned this repository with submodules and have had the appropriate access to the submission repository.

## Terse Description

Convex (Kaasalainen) inversion jointly fit to simulated intensity and binary (occultation) lightcurve data, optimizing facet areas under convexity regularization and reconstructing the mesh via a Minkowski solve.

For longer description, refer to the report in [`/report/`](/report/).
