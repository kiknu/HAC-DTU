This folder contains submission 3 for the Technical University of Denmark (DTU) team to the challenge.

The full submission repository is present as a _Git Submodule_ in [`submission_repo/`](submission_repo/) and accessible if you have cloned this repository with submodules and have had the appropriate access to the submission repository.

## Terse Description

`lc2mesh` using a per-asteroid INR: a SIREN deforms an ellipsoid prior, a graph CNN refines the mesh, and both are optimized through a differentiable mistuba rendering forward model

For longer description, refer to the report in [`/report/`](/report/).
