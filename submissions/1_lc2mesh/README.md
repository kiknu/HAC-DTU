## Terse Description

`lc2mesh` using a per-asteroid INR: a SIREN deforms an ellipsoid prior, a graph CNN refines the mesh, and both are optimized through a differentiable photometric forward model.

For longer description, refer to the report in [`/report/`](/report/).
