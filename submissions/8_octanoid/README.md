# Submission 8 – Non-Convex Inversion using Octantoid Representation and Differentiable Forward

This folder contains submission 8 for the Technical University of Denmark (DTU) team to the challenge.

- Submission Repository: [kiknu/HAC-DTU](https://github.com/kiknu/HAC-DTU) (branch `pytorch3D-adam-optimizer`)
- Submission Responsible: Michael Ruben Johansen `<s252972@student.dtu.dk>`

The submitted reconstructions may be found in [`submitted_reconstructions/`](submitted_reconstructions/).

The full submission repository is present as a _Git Submodule_ in [`submission_repo/`](submission_repo/) and accessible if you have cloned this repository with submodules and have had the appropriate access to the submission repository.

## Terse Description

Non-convex inversion with a degree-6 octantoid shape model, fit through a differentiable PyTorch3D renderer over all 21 independent challenge camera geometries using Adam optimization.

For longer description, refer to the report in [`/report/`](/report/).
